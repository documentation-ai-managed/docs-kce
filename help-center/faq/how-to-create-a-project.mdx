## Steps to Create

1. Log in to your KCE dashboard.
2. Click "New Project" on the main page.
3. Enter a project name and description (optional).
4. Click "Create" to finish setup.

## Tip

<Callout kind="info">
You can invite teammates after your project is created.
</Callout>
