## How to Add a Doc Page

<Steps>
  <Step title="Go to Project">
    Select your project from the KCE dashboard.
  </Step>
  <Step title="Click 'Add Page'">
    Find and click the "Add Page" button.
  </Step>
  <Step title="Enter Details">
    Set a page title and optional content.
  </Step>
  <Step title="Save">
    Click "Save" to publish your new documentation page.
  </Step>
</Steps>
